# Aevra 0.1.0

Windows üzerinde yerel çalışan kişisel yapay zekâ: sohbet, çeviri, matematik, kodlama ve kaynaklı web araştırması.

## Windows kurulumu

1. Aşağıdaki Assets bölümünden `Aevra-0.1.0-windows-x64-setup.exe` dosyasını, **beş `.bin` dosyasının tamamını** ve `SHA256SUMS.txt` dosyasını indirin. Toplam indirme yaklaşık **7,35 GB**'tır.
2. Bu yedi dosyayı isimlerini değiştirmeden **aynı klasöre** koyun.
3. `Aevra-0.1.0-windows-x64-setup.exe` dosyasını çalıştırın.

EXE tek başına kurulumu tamamlayamaz. GitHub'ın **Source code (zip / tar.gz)** bağlantıları uygulama kurulumu değildir. Model, görsel bileşen, CPU/Vulkan motorları ve çevrimdışı WebView2 kurulumda bulunur; ayrıca Ollama, Python veya geliştirme aracı kurulmaz.

## Bu sürümde

- Qwen3.5-9B Q4_K_M ile yerel üretim; CPU, GPU ve Otomatik seçimi.
- 11 hedef dilde çeviri; PDF, Word, görsel, metin ve ZIP ekleri.
- Matematik formülleri, kod gösterimi ve formülleri koruyan PDF dışa aktarma.
- Google kullanan görünür araştırma tarayıcısı ve bağlantılı kaynaklar.
- SQLite sohbet geçmişi, yarım kalan yanıtların kaydı, arşiv ve JSON yedekleri.
- Yönetilebilir otomatik kişisel hafıza; açık/koyu tema ve kişiselleştirme.

## Gereksinimler ve bilinen sınırlar

Windows 10 22H2 / Windows 11 x64; en az 16 GB RAM, büyük belge ve görseller için 24–32 GB önerilir. GPU kullanımı uyumlu Vulkan sürücüsü ve yeterli belleğe bağlıdır; hız bilgisayara göre değişir.

Bu ilk dağıtım kod imzalı değildir; Windows yayıncı uyarısı gösterebilir. Temiz Windows sanal makinesindeki çevrimdışı kurulum/kaldırma kabul testi henüz tamamlanmadı. Otomatik güncelleme yoktur.

Sohbetler ve kişisel hafıza bu bilgisayarda tutulur; veritabanı bu sürümde şifrelenmez. Araştırma sırasında arama hizmetleri ve ziyaret edilen siteler IP adresinizi ve gönderilen sorguları görebilir. Model yanıtları hata içerebilir; önemli bilgileri doğrulayın.

## İndirmeyi doğrulama

PowerShell'i indirilen dosyaların bulunduğu klasörde açın:

```powershell
Get-Content .\SHA256SUMS.txt | ForEach-Object {
    $expected, $name = $_ -split '  ', 2
    if ((Get-FileHash -LiteralPath $name -Algorithm SHA256).Hash.ToLowerInvariant() -ne $expected) {
        throw "Dosya doğrulanamadı: $name"
    }
    Write-Output "Doğrulandı: $name"
}
```
